# TG-263 implementation

Reference: [AAPM TG-263, January 2018](https://www.aapm.org/pubs/reports/RPT_263.pdf), sections 7–10. Vocabulary: [official worksheet, 20170815](https://www.aapm.org/pubs/reports/rpt_263_supplemental/TG263_Nomenclature_Worksheet_20170815.xls), obtained from the [AAPM resource page](https://www.aapm.org/pubs/reports/rpt_263_supplemental/) on 21 October 2026. The JSON catalogue retains 717 primary/reverse pairs and the source SHA-256. Cell padding in three primary names was trimmed; original values remain alongside them. This snapshot is versioned, not automatically updated.

`analyze_dvh` now reports naming checks before calculating requested structures. It requires unique ROI numbers and names regardless of case. Selection preserves laterality, PRV, partial-volume and segmentation indicators; substring matches are disabled. Original DICOM names remain intact. The preferred primary vocabulary, scoped PRV/partial-volume derivations and a documented subset of target syntax are recognized. Case differences are reported. Reverse names and other unrecognized forms require review rather than automatic substitution.

Legacy names require a caller-supplied `reviewed_name_map`, for example `{"Cord": "SpinalCord"}` after anatomical review. Mappings are exact source-name keys. Mapping destinations must be recognized; collisions and missing source keys fail. An unreviewed structure returns `found: false` and a diagnostic, without metrics. Naming checks do not validate anatomy or prescriptions.

The target parser supports type, classifier, enumerator, dose level, physical dose/fractionation and cropping. Imaging/anatomic qualifiers, custom qualifiers and compressed target forms need review; they are not declared noncompliant. Relative dose levels are preferred; names carrying physical dose are labels, never prescription inputs. Reverse, custom and other unsupported valid forms need extension of this scoped checker before they can be used as canonical destinations. Segmentation markers are retained but their geometric meaning is not inferred.

Canonical metric output uses explicit input/output units: `D95%[Gy]`, `D50%[Gy]`, `D2%[Gy]`, `V50Gy[%]`, `V50Gy[cc]`. Existing Python keys remain compatibility aliases. Naming conventions do not resolve the audit's uncommissioned DVH sampling and uncertainty limitations. Clinical release remains blocked.

The Streamlit workflow exposes exact ROI names, reviewed JSON mapping and the naming report. Agent prompts require reporting unresolved names. Regression tests cover the entire pinned primary vocabulary, representative target/derived names, collisions, unit labels, and synthetic DVH integration with an explicitly reviewed legacy mapping.
